# Agente de Marketing Digital

Base FLUX importada do repositório GitHub `foiassimumsonho/Agente-de-marketing`.

A aplicação é apresentada como **Agente de Marketing Digital** e concentra criação de arquétipos, sugestões de posts multiformato e conversas assistidas. O módulo Histórico de Gerações registra no navegador arquétipos, posts e conversas, incluindo tipo, formato, briefing, resultado e data.

Todo material gerado permanece como sugestão para revisão humana. A aplicação não publica automaticamente em Instagram, TikTok, Pinterest ou qualquer outra rede social.

## Estrutura

- `backend/`: API FastAPI e routers de integrações.
- `frontend/`: interface HTML do Agente de Marketing Digital.
- `requirements.txt`: dependências Python da base original.
- `Procfile` e `railway.json`: referências de execução do pacote.
